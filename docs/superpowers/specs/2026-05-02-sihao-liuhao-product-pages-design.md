# 四好/六好产品页上架设计文档

**日期**：2026-05-02  
**状态**：已确认（待进入实现计划）  
**范围**：新增四好、六好两款产品的宣传页面并接入产品中心

---

## 1. 背景与目标

当前站点已上线多款产品宣传页，但四好学生、六好学生尚未上架。目标是在不改知识库的前提下，基于知识库已有资料补齐两款产品页面，用于官网宣传展示。

本次重点是“可展示、可咨询、信息完整”，不做教程承载。

---

## 2. 需求边界（已确认）

### In Scope

1. 在产品中心新增四好、六好卡片入口。  
2. 新增 `/products/sihao` 和 `/products/liuhao` 两个独立详情页。  
3. 从知识库提取宣传内容（卖点、参数、模块、交付支持）并落地到页面。  
4. 复制所需图片到 `public/images/products/` 并在页面静态引用。  
5. 完成类型检查和 lint。

### Out of Scope

1. 不改知识库文档。  
2. 不做教程内容上网页（命令行、操作步骤、教学流程全部排除）。  
3. 不做动态导入/解析知识库。  
4. 不扩展为 Wiki 站点。

---

## 3. 信息架构与页面结构

四好、六好两页统一采用现有产品页风格，结构如下：

1. Hero（定位、核心卖点、主图、咨询按钮）  
2. 核心参数（卡片化指标）  
3. 模块配置（飞控/雷达/机载电脑/相机等）  
4. 关键能力（导航/建图/识别等宣传能力，不含步骤）  
5. 详细规格（电池、续航、体积、重量、精度）  
6. 服务与交付（二次开发、维护、发票等）  
7. CTA（联系咨询）

---

## 4. 内容提取策略

### 四好学生（`docs/content-library/products/sihao.md`）

保留内容：

- 产品定位与价值主张（降低开发门槛、高性价比）  
- 核心模块：Pix4、Mid360、Jetson Orin NX Super、D435  
- 核心参数：电池、最大起飞重量、续航、重量、轴距、定位精度  
- 宣传能力：定位、建图、导航、探索、识别（以能力描述呈现）  
- 交付支持：二次开发、维护支持、发票

过滤内容：

- 教程/命令/运行步骤（本文件中较少）

### 六好学生（`docs/content-library/products/liuhao.md`）

保留内容：

- 产品定位：高性能、多功能、小巧灵活、FastLivo2定位能力  
- 更新亮点：减震、防炸机保护、视觉识别优化  
- 核心模块：工业级/Nxt PX4、Mid360、Jetson Orin NX Super、USB相机  
- 关键参数：起飞重量、续航（5寸/7寸）、体积、定位精度、整机重量  
- 宣传能力：SLAM、自主避障导航、自主探索、智能识别（仅能力，不放步骤）  
- 交付支持：二次开发、维护支持、发票

过滤内容：

- 大量命令行与分步教程（`./3DSLAM.sh`、`roslaunch ...` 等）  
- 新手操作指南、遥控器细节操作流程、网络配置步骤

---

## 7. 风险与处理

1. **六好图片较少**：通过“参数模块化 + 能力卡片 + 信息层次”提升页面完整度。  
2. **六好知识库教程占比高**：严格做“宣传抽取”，避免教程内容误入页面。  
3. **文档数据噪声**：对含糊字段（如“整机重量”空值）使用已明确字段，不编造参数。

---

## 8. 验收标准

1. 产品中心可见四好/六好两张卡片并可跳转详情页。  
2. 两个详情页结构完整、风格统一、可正常访问。  
3. 页面仅包含宣传内容，不包含教程命令与操作步骤。  
4. 图片路径可访问，无 404。  
5. `npm run check-types` 与 `npm run lint` 通过。

---

## 9. 实施建议

采用“先四好后六好”的顺序：

1. 四好素材更完整，先建立页面结构模板。  
2. 六好复用同构版式，替换为六好内容与2张专属图。  
3. 最后统一更新产品中心数据并做整体验证。
